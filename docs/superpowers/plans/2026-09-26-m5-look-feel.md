# ShinobiCoop M5 (Look & Feel): Lean Plan

**Goal (spec §4 Arena; §5 Toon look, Audio; milestone M5):**
- a toon post-process;
- the "Training Grounds" arena;
- hit-stop, camera shake, damage numbers and placeholder audio;
- a map picker on Host Game (user request), with `Lvl_Combat` made playable.

**Process:** lean, inline, in chunks with a light check (screenshots) at the end. Branch `feature/m5-look-feel`, stacked on the unmerged `feature/m4-steam`, whose two-PC playtest is still pending.

## Decisions (deviations noted)

| Topic | Decision |
|---|---|
| Toon post-process | `M_ToonPost` (built by script), after tonemapping. One Custom HLSL node: lighting = scene colour ÷ diffuse colour, posterised into 3 soft bands and re-multiplied. Pixels with no diffuse (emissive VFX, sky) are left alone. Outlines come from a cross-shaped depth and normal edge test, plus a slight saturation boost. It's a blendable on each arena map's unbound post-process volume. |
| Arena | `Lvl_TrainingGrounds`, built by `Scripts/setup_m5.py` from engine primitives with flat-colour materials (`M_ShinobiSolid` + instances): grass clearing (80 m), tree and rock ring (trunk cylinders + cone canopies), invisible wall ring, torii gate, training posts, cover rocks, sky, sun, fog. A PlayerStart sits in the centre, with 4 `ShinobiEnemySpawn` target points on the perimeter, which the arena now spawns around (the 1200-unit ring stays as the fallback). A NavMesh bounds volume covers the clearing. |
| Navigation | **Deviation:** the navmesh is generated at runtime (`RecastNavMesh RuntimeGeneration=Dynamic`) instead of being built into the map, because scripts can't reliably build nav in a commandlet. The AI uses `MoveToActor` (strafing, keeping its focus) and falls back to straight-line steering when there's no path (`Lvl_ThirdPerson`, tests). |
| Damage numbers | Cosmetic and client-side: every machine watches each character's replicated Health, and a drop spawns a floating number (white on enemies, red on players, big when ≥ 20). **Deviation:** no gameplay cues, as in M2b. Hits within one net update merge into one number. |
| Hit-stop / shake | A drop of ≥ 20 freezes the victim's animation for 0.08 s (anim rate only, never movement or timers). Camera shake uses the template's `BP_CameraShake_Hit_Player` when the local player is hit, and `BP_CameraShake_Hit_Enemy` when an enemy within 400 units of the local player takes ≥ 20. |
| Audio | **Deviation:** there's no Starter Content, so `Scripts/make_sfx.py` (stdlib Python) synthesises placeholder WAVs into `SourceArt/Audio` and `setup_m5.py` imports them. Sounds play on every machine: montage starts (swing, dodge, cast), bursts (explosion, zap, whirr, poof), damage (impact), and wave start / victory on the HUD. |
| Map picker | Host Game lists the maps: Training Grounds (default), Test Level (`Lvl_ThirdPerson`), Combat Level (`Lvl_Combat`, with its template enemy spawners removed by script). The session carries the map name, and Find Games shows it. |

Known limits:
- On `Lvl_Combat` (no spawn points), an enemy from the fallback 1200-unit ring can land off the floor. The arena counts it out, so the wave still ends.
- Damage numbers from rapid hits stack; that's fine for now.

## Manual playtest

Run `Scripts/play.ps1` (menu), or open `Lvl_TrainingGrounds` in PIE.

| # | Check |
|---|---|
| 1 | Host Game shows "Host on Training Grounds / Test Level / Combat Level", and each one loads in wave mode. Find Games shows the map name. |
| 2 | Training Grounds: an 80 m grass clearing, a tree and rock ring you can't walk out of, torii, training posts, cover rocks, sky and clouds. |
| 3 | Toon look: flat light / shadow bands and dark outlines on characters and props, with no harsh noise at distance. Jutsu glows unaffected. |
| 4 | Enemies path around rocks and posts (navmesh), not into them. |
